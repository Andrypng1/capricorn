# Contribuir a Capricorn

Usa Windows x64, Node.js 24 LTS y npm. Ejecuta `npm ci` y `npm run build:credentials` antes de probar la aplicación con `npm start`.

Antes de abrir una propuesta, ejecuta `npm run lint`, `npm test` y `npm run build`. En Windows también puedes ejecutar `npm run test:desktop`.

Usa datos ficticios en pruebas, capturas e incidencias. Excluye claves, bases de datos, archivos .capricorn y cualquier dato de clientes. Reporta vulnerabilidades por el canal privado de [SECURITY.md](SECURITY.md).
